# Cris & Vini — The Wedding Experience

Independent bilingual destination-wedding guest guide.

## Project decisions
- Separate repository from the original invitation website.
- Original invitation repository is not modified.
- Portuguese is the default language; English is available from the header.
- Wedding gathering: 22–25 April 2027.
- Wedding day: 24 April 2027.
- Venue: Hotel Transamerica Comandatuba, Ilha de Comandatuba, Bahia, Brazil.
- No RSVP form or guest response collection in this project.
- Opens directly into the magazine-style homepage; no envelope animation.

## Local preview
Open this folder in Visual Studio Code and use the Live Server extension. Open `index.html` with Live Server.

## GitHub Pages
Create a new repository named `cris-vini-wedding-guide`, upload the contents of this folder to the repository root, then enable Pages from `main` / root.

Expected URL: `https://ttianee.github.io/cris-vini-wedding-guide/`
